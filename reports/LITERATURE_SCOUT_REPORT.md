# 大学生学习效率 DEA 系统：最新文献与创新路线报告

检索日期：2026-09-21  
检索对象：大学生学习效率、教育效率、Network DEA、SBM/Super-SBM、Malmquist、Meta-frontier、DEA 与人工智能融合。  
检索方式：结构化检索（OpenAlex、Semantic Scholar、Crossref、arXiv）+ 出版商/开放获取页面核验。

> 说明：本文是技术路线与文献证据整理，不构成专利新颖性/创造性法律意见。专利申请前仍需进行正式的专利查新和权利要求对比。

## 1. 先给结论

当前系统已经具备 CCR/BCC、SBM、超效率 SBM、Malmquist、数据校验、公开学生数据和网页化展示能力，作为软著原型是成立的；但作为论文或发明专利，仅描述“上传成绩数据后自动计算 DEA”不够形成强创新。

目前最重要的近似工作是 Yang（2024）的学生学习效率研究：该文把 DEA、数据融合、聚类和 DEA-Malmquist 用于高校学生学习效率分析。因此，“学生成绩 + DEA + Malmquist”不能作为本项目的核心独创点，而应作为基线对照。论文页面和全文信息见 [Yang 2024](https://doi.org/10.2478/amns-2024-0371)。

建议把系统升级为：

> **面向大学生学习过程的分阶段动态网络 DEA 稳健诊断系统**

核心不是给学生做一个简单排名，而是将“学习投入 → 学习过程 → 学业产出”拆开测量，并同时给出阶段效率、瓶颈环节、同类群体前沿、Bootstrap 置信区间和可执行改进目标。

### 2.2 文献共识

近期工作大致沿着五条路线推进：

1. **从黑箱 DEA 转向 Network DEA**：将教学、科研、成果转化或学生学习过程拆成相互连接的子阶段。
2. **从同质前沿转向异质群体前沿**：用 Meta-frontier、聚类、层级网络或技术差距比处理地区、学校类型、规模和专业差异。
3. **从点估计转向稳健效率**：用 Bootstrap、偏差修正、置信区间和排序稳定性降低小样本与异常值影响。
4. **从静态效率转向动态生产率**：用 Global Malmquist、动态 DEA 或 carry-over 变量处理多学期变化。
5. **从计算结果转向决策支持**：不仅报告分数，还要指出瓶颈、参考对象、投入/产出调整量和可执行的干预方向。

## 3. 与当前系统的差距

当前系统是“单个学生作为 DMU，投入为课程/学习资源，产出为通过数和平均成绩”的静态相对效率评价。这个定位适合演示和软件原型，但存在以下研究缺口：

### 3.1 学习过程仍是黑箱

当前模型把选课数、通过数和成绩直接放入同一个投入—产出关系中，没有区分“投入了多少”“是否真正参与学习”“最终形成了什么成绩”。这会掩盖学生低效率究竟发生在学习投入不足、过程参与不足，还是知识产出不足。

### 3.2 结果是点估计，缺少不确定性

DEA 前沿由样本中的极少数 DMU 构成，样本量、异常值和指标选择都会影响排名。当前系统给出一个效率分数，但没有给出置信区间、偏差修正和排名稳定性。

### 3.3 默认把所有学生放入同一前沿

不同专业、年级、课程负荷、学习方式和基础水平的学生不一定适合直接比较。若直接将所有学生混合建模，系统可能把群体差异误判成个人效率差异。

### 3.4 Malmquist 需要真正的匹配期数据

Malmquist 不是“有两个成绩字段就可以计算”。它要求同一 DMU 在两个或多个时期具有可比的投入、产出和前沿。当前公开演示数据适合展示，老师提供的多学期学生数据才适合做正式动态研究。

### 3.5 影响因素不能直接解释为因果

DEA 可以告诉我们相对效率和改进方向，但不能单独证明“某个因素导致成绩下降”。如果要分析学习行为、家庭背景、课程难度或教学方式的影响，需要将 DEA 结果与 Bootstrap 截断回归、Tobit、面板模型或因果方法分开设计。

## 4. 推荐的创新方案

### 创新一：分阶段学生学习网络 DEA（建议作为主创新）

将学生学习过程建模为：

```text
学习投入 X  →  学习参与/过程 Z  →  学业产出 Y
```

一个可落地的变量方案是：

| 阶段 | 指标示例 | 作用 |
|---|---|---|
| 初始投入 X | 选课数、学习时长、平台访问次数、出勤投入、学习资源使用量 | 表示学生投入的资源和机会 |
| 中间产出 Z | 作业提交率、课堂参与度、阶段测验完成率、课程互动次数 | 表示学习过程是否有效转化 |
| 最终产出 Y | 通过课程数、平均成绩、学分获得率、课程完成率 | 表示可观察的学业结果 |
| 非期望产出 B | 缺勤次数、补考次数、退课/挂科次数、逾期提交次数 | 表示学习过程中的负向结果 |

系统输出不再只有一个总分，而是：

- 总体网络效率；
- 投入—参与阶段效率；
- 参与—成绩阶段效率；
- 瓶颈阶段；
- 阶段内松弛变量和改进目标；
- 同类高效学生参考集合。

**创新价值**：把教育管理问题映射到可计算的多阶段生产过程，解决传统学生 DEA 的黑箱问题。它与现有“DEA + Malmquist”相比，创新点在结构，而不是模型名称的叠加。

### 创新二：Bootstrap 稳健效率与排序稳定性

对学生样本进行重复重采样，获得每名学生的效率分布，而不是只返回单次效率值。界面可以同时展示：

- 原始效率；
- 偏差修正效率；
- 95% 置信区间；
- 排名稳定性；
- “确定低效”“边界不确定”“稳定高效”三类标签。

**创新价值**：学生数量少、指标多时，单个效率分数容易过度解读。这个模块可以把系统从“计算器”提升为“稳健诊断工具”。

### 创新三：面向专业/年级/课程负荷的群体元前沿

先按专业、年级或课程负荷形成相对同质的群体，在群体内计算前沿，再构造总体 Meta-frontier。输出：

- 群体内效率；
- 总体前沿效率；
- 技术差距比；
- “个人效率不足”与“群体资源/技术差异”的分解。

**创新价值**：避免把不同教育环境下的学生进行不公平的直接比较。该方向已有高校层面的研究基础，但面向学生学习过程、并与网络 DEA 和干预建议组合，仍有较强的应用创新空间。注意：不能声称“首次使用 Meta-frontier”，应准确表述为面向大学生学习过程的适配与系统化实现。

### 创新四：多学期动态学习轨迹

当老师提供同一学生的多学期记录后，计算：

- Global Malmquist 生产率指数；
- 技术效率变化 EC；
- 技术进步 TC；
- 纯技术效率变化和规模效率变化；
- 阶段效率的学期变化。

系统将学生分成“效率提升、投入增加但产出未跟上、效率下降、稳定高效”等轨迹类型。这里建议使用真实多学期匹配数据，公开演示数据只作为原型验证。

### 创新五：数据语义识别与模型推荐

这是软件/系统层面的特色：系统读取字段名、取值范围、缺失率、零值比例和时间字段，自动提出：

- 哪些字段更适合作为投入、产出、中间变量或非期望产出；
- 是否存在负数、全零、重复 DMU、重复投入/产出；
- 应使用 CCR、BCC、SBM、Super-SBM、Network DEA 还是 Malmquist；
- 当前数据是否满足动态模型要求；
- 哪些结果只能作为相对比较，不能解释为因果关系。

**创新价值**：这是把 DEA 理论封装为可复用决策系统的关键，也是软著说明书中最容易清晰展示的功能链。但若申请发明专利，必须进一步固化自动推荐规则、约束处理和输出机制，避免只描述普通的数据导入与按钮调用。

## 5. 建议的主线组合

不要一次把所有模型都堆进去。建议按下面的优先级推进：

### 论文主线

**网络 DEA + Bootstrap + 群体元前沿**

研究问题：在考虑学习过程结构、学生群体异质性和估计不确定性的情况下，如何识别大学生学习效率瓶颈？

实验对照：

1. CCR/BCC；
2. SBM/Super-SBM；
3. 两阶段 Network SBM；
4. Network SBM + Bootstrap；
5. Network SBM + Bootstrap + Meta-frontier。

评价指标：效率均值、有效 DMU 数量、排名相关性、Bootstrap 区间宽度、群体间差异、改进目标可解释性。

### 系统/软著主线

**数据导入 → 数据语义审计 → 模型推荐 → 多模型计算 → 稳健性检查 → 瓶颈诊断 → 个性化报告**

这样写，系统的创新点是“自动化、可审计、可解释、可追溯的学生学习效率诊断流程”，而不是“网页中集成若干 DEA 公式”。

### 专利主线

建议将权利要求聚焦于一个闭环：

> 根据学生多源学习数据识别投入、过程、中间产出、最终产出和非期望产出；按照学生群体异质性构建分阶段 DEA 前沿；通过 Bootstrap 得到稳健效率区间；依据阶段松弛量和参考 DMU 生成个性化学习改进目标。

其中“输入字段识别、阶段映射、群体前沿、稳健区间、改进建议”需要在代码、流程图和实施例中一一对应，才有机会形成较完整的技术方案。

## 6. 当前系统应补充的验证实验

1. **指标敏感性**：分别移除“选课数、通过数、平均成绩、学习过程字段”，观察效率排名变化。
2. **样本敏感性**：使用公开数据的不同子样本和老师提供的真实数据重复计算。
3. **模型一致性**：验证 CCR、BCC、SBM、Super-SBM 在同一数据上的方向、规模报酬和投影关系。
4. **Bootstrap 稳定性**：报告效率区间和排名稳定性，不只报告均值。
5. **群体公平性**：比较全体前沿、专业内前沿和 Meta-frontier 下的结果差异。
6. **动态一致性**：确保同一学生在多个学期均有完整 DMU 记录后再计算 Malmquist。
7. **外部效度**：用真实学生数据验证改进建议是否与教师认知、课程结果或后续成绩一致。

## 8. 最终建议

现阶段最值得做的不是继续美化界面，也不是简单再增加一个 DEA 模型，而是把系统升级成一个有明确理论主线的原型：

> **网络化刻画学习过程，Bootstrap 量化结果可信度，Meta-frontier 处理群体差异，动态模型识别学习轨迹，规则引擎生成可执行建议。**

其中第一阶段优先完成“二阶段 Network SBM + 阶段诊断 + 数据校验”，第二阶段再加入 Bootstrap 和群体元前沿，第三阶段用老师的多学期数据验证动态 Malmquist。这样既能形成论文方法主线，也能支撑软著和后续专利材料。
