# 网络 DEA 优化结果记录

## 运行环境

- 项目：智能大学生学业成绩因素评估系统 V1.4
- 数据：`data/uci_higher_education_dea_sample.csv`
- 样本：180 个学生 DMU
- 规模报酬：BCC / VRS
- 随机种子：42
- 运行时间：2026-09-21

## 数据读取与预处理

本次验证使用公开 UCI 高等教育学生样本。网络模型采用：

- 阶段 1 投入：第一学期选课数、第二学期选课数；
- 阶段 1 中间过程：第一学期考核次数、第二学期考核次数；
- 阶段 2 最终产出：第一学期通过课程数、第二学期通过课程数、第一学期平均成绩、第二学期平均成绩。

数据校验通过：DMU 唯一、字段为非负数、三类指标均存在且每个 DMU 的三类指标合计均大于 0。

## 两阶段网络 DEA 结果

| 指标 | 数值 |
| --- | ---: |
| DMU 数量 | 180 |
| 网络效率为 1 的 DMU 数量 | 1 |
| 平均网络效率 | 0.088424 |
| 平均阶段 1 效率 | 0.212835 |
| 平均阶段 2 效率 | 0.390412 |

在该公开演示口径下，阶段 1 平均效率低于阶段 2，说明投入到学习过程的转化是更明显的瓶颈。这个结论只适用于当前样本和指标定义，不代表真实学校学生群体的普遍规律。

网络效率满足 `sqrt(阶段1效率 × 阶段2效率)` 的实现口径，结果均位于 0 到 1 区间内。
