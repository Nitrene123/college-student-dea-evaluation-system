## 1. 总体建模框架

本项目把每一行学生记录视为一个决策单元（DMU），评价其在当前样本前沿下将学习投入转化为学习过程，再转化为学业结果的相对效率。

```text
数据导入 → 字段与数值校验 → 阶段语义配置
        → 阶段1：学习投入 → 学习过程
        → 阶段2：学习过程 → 学业结果
        → 网络效率与瓶颈诊断
        → Bootstrap 稳健性 / 群体元前沿
        → 标杆、改进项和可下载结果
```

当前代码采用透明的“两阶段串联 SBM 诊断实现”：两个阶段共享同一组中间过程指标，但分别建立参考前沿并计算阶段效率；网络效率取两个阶段效率的几何平均。该实现适合系统原型和论文方法验证，后续如需投稿更高水平期刊，可继续替换为具有联合链接约束的正式 Network SBM。

## 2. 数据与指标语义

| 类别 | 符号 | 语义 | 示例 |
| --- | --- | --- | --- |
| 学习投入 | X | 学习资源或课程负荷 | 选课数、学习时长、学习资源使用量 |
| 学习过程 | Z | 投入转化后的过程性行为 | 考核次数、出勤率、作业完成率、课堂参与度 |
| 学业产出 | Y | 最终学习结果 | 通过课程数、平均成绩、获得学分、课程完成率 |

所有指标要求为非负数。各 DMU 在每一类指标中的合计不能为 0，以避免 SBM 比例项失去定义。

## 3. 假设敏感性预检

### 模糊表述及解释

1. “学习因素”可以解释为直接原因变量，也可以解释为投入—产出效率指标。前者需要回归或因果设计，后者适合 DEA。本系统采用后者。
2. “学生成绩”可以直接作为最终产出，也可以将出勤、作业和参与作为中间产出。本系统采用第二种解释，以解决传统 DEA 把学习过程压缩成黑箱的问题。
3. “群体公平比较”可以解释为按群体分别建前沿，也可以解释为给不同群体设置主观权重。本系统采用群体前沿与总体元前沿比较，不引入未经验证的主观权重。
4. “动态效率”需要同一学生在至少两个时期出现，不能用同一学生的两个成绩字段替代真实时期记录。Malmquist 仅对真正匹配的面板数据启用。

### 快速验算与递进性检查

- 如果阶段 1 效率明显低于阶段 2，诊断应指向投入到学习过程的转化瓶颈；反之应指向过程到成绩的转化瓶颈。
- 网络效率使用 sqrt(阶段1效率 × 阶段2效率)，因此不会超过两个阶段中的较高者，也不会超过 1。
- 群体内前沿使用同群体参考 DMU，元前沿使用全体参考 DMU；两者差异只能解释为前沿环境/技术差异，不能直接解释为群体属性造成的成绩差异。
- Bootstrap 区间宽度较大时，系统标注“边界不确定”，不把单点排名当作稳定结论。

### 最终采用的解释

采用“学习资源投入 → 学习过程 → 学业结果”的串联效率解释；把 CCR/BCC、SBM、Network SBM、Bootstrap 和 Meta-frontier 分别作为基线、主模型、稳健性和异质性模块，不把模型分数解释为因果效应。

## 4. 两阶段学习过程网络 SBM

### 4.1 目标

同时识别学生整体网络效率和两个学习转化阶段的效率，回答：

- 学生的主要问题在投入—过程阶段还是过程—成绩阶段？
- 哪些学生可以作为同阶段标杆？
- 哪些投入存在冗余，哪些过程指标或学业产出不足？

### 4.2 符号

- i = 1,...,n：DMU；
- X_i：阶段 1 投入；
- Z_i：阶段 1 产出、阶段 2 投入的中间过程指标；
- Y_i：阶段 2 最终产出；
- E_1i：阶段 1 SBM 效率；
- E_2i：阶段 2 SBM 效率。

### 4.3 阶段 SBM 线性化求解

对任一阶段，给定参考技术集合和待评价目标，使用 Charnes–Cooper 变量 t、lambda、s_minus、s_plus 求解：

```text
sum(lambda_r * X_r) + s_minus = t * x_0
sum(lambda_r * Y_r) - s_plus = t * y_0
```

BCC 约束为 `sum(lambda_r) = t`，CCR 不添加该约束。归一化约束为：

```text
t + mean(s_plus / y_0) = 1
```

目标函数为投入冗余与产出不足的非径向 SBM 目标：

```text
min t - mean(s_minus / x_0) - mean(s_plus / y_0)
```

代码接口为 `_solve_sbm_target(reference_x, reference_good_y, target_x, target_good_y, model)`。

### 4.4 网络综合效率

两个阶段分别计算：

```text
E_1i = SBM(X → Z)
E_2i = SBM(Z → Y)
E_Ni = sqrt(E_1i * E_2i)
```

该组合能够突出短板阶段，并保持 0 ≤ E_N ≤ 1。页面同时输出瓶颈阶段和阶段松弛项。

### 4.5 输出

- 网络SBM效率；
- 阶段1效率、阶段2效率；
- 瓶颈阶段和阶段差值；
- 阶段 1/2 参考标杆及权重；
- 阶段投入冗余、过程不足、过程冗余和产出不足。

## 5. Bootstrap 稳健性分析

### 5.1 目标

检验学生效率和排名是否受样本前沿扰动影响，避免把单次 DEA 点估计当作确定结论。

### 5.2 算法

1. 固定随机种子，按学生 DMU 有放回抽取与原样本同等规模的参考样本；
2. 对每个学生分别计算两个阶段效率及其网络几何平均；
3. 重复 B 次，得到每名学生的网络效率经验分布；
4. 输出均值、2.5% 分位数、97.5% 分位数和偏差修正效率：
   `E_bc = 2 * E_original - mean(E_bootstrap)`；
5. 检查各次重采样与原始排序的平均秩相关系数。

网页演示默认使用较少重复次数保证响应速度；正式论文实验建议使用至少 100 次，并将随机种子、重复次数和结果 JSON 固化。

## 6. 群体元前沿比较

### 6.1 目标

针对专业、年级、课程负荷等群体构造群体内参考前沿，同时以全体样本构造总体元前沿，区分个人相对效率和群体技术环境差异。

### 6.2 指标

- E_g：学生在所属群体前沿下的网络效率；
- E_M：学生在全体元前沿下的网络效率；
- 技术差距比：`TGR = E_M / E_g`，在当前比较口径下取值不超过 1。

当群体样本少于 3 个时，不计算群体内前沿，只保留元前沿结果。

### 6.3 输出

- 学生层面的群体内效率、元前沿效率、技术差距比；
- 群体样本量、群体平均效率和平均技术差距比；
- 群体之间的对照表。

该结果是公平比较和诊断工具，不是专业或群体属性的因果估计。

## 7. 数据条件、风险与替代方案

| 风险 | 影响 | 当前处理 | 论文替代方案 |
| --- | --- | --- | --- |
| 公开样本缺少完整学习行为轨迹 | 阶段 1 的过程含义较弱 | 使用考核次数作为学习过程代理 | 用教师的 LMS、出勤、作业和多学期记录验证 |
| 学生样本量不足 | 前沿和 Bootstrap 不稳定 | 输出区间和稳定性标签 | 扩大多班级、多学期样本，并做敏感性分析 |
| 指标选择主观 | 效率排名可能变化 | 页面显示字段配置 | 做指标删除/替换实验和专家一致性验证 |
| 群体前沿样本过少 | 群体效率不可识别 | 少于 3 个 DMU 时跳过群体前沿 | 合并小群体或使用层级模型 |
| DEA 相对效率被误解为因果 | 教育决策风险 | 页面和报告明确非因果 | DEA 后接 Bootstrap 截断回归或因果研究设计 |
| 复杂网络模型计算时间较长 | 网页交互延迟 | 演示次数较少，论文次数提高 | 离线批处理并保存结果 JSON |
