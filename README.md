# 智能大学生学业成绩因素评估系统 V1.3

这是一个面向大学生学习投入—学习结果相对效率评价的运筹学 DEA（Data Envelopment Analysis，数据包络分析）网页系统。系统将每一行学生或班级数据视为一个决策单元（DMU），由教师指定学习资源投入、学习结果和课程成绩，自动计算相对学业效率、参考标杆和改进方向。系统默认优先加载公开的 UCI 高等教育学生数据，教师也可以上传自有数据。

## 当前功能

- 支持内置演示数据和 CSV、TSV、Excel、Parquet 文件上传。
- 支持 CCR（固定规模报酬）和 BCC（可变规模报酬）模型。
- 支持投入导向和产出导向。
- 自动计算 DEA 效率、CCR 效率、BCC 效率和规模效率。
- 判断规模报酬不变、递增或递减。
- 输出参考标杆及其权重。
- 计算投入压缩和产出提升的投影目标。
- 支持标准 SBM、超效率 SBM，以及非期望产出（如医疗废弃物、碳排放）的松弛变量分析。
- 支持 Malmquist 指数，输出效率变化 EC、技术进步 TC 和生产率变化。
- 提供 CCR/BCC 数值校核：效率边界、CCR/BCC关系、规模效率上界和结果数量一致性。
- 以数据风、科技风网页端展示效率排名和改进诊断。
- 提供 UCI 高等教育学生公开 DEA 演示样本、大学生学业成绩示例数据和 CSV 模板，支持学号、专业班级、学习时长、出勤率、作业完成率、课堂参与度和课程成绩字段。
- 明确区分“相对学习效率评价”和“成绩因果影响分析”，避免将 DEA 结果误解为单因素因果结论。

## 公开数据

- `data/uci_higher_education_dea_sample.csv`：基于 UCI 数据集 697 的 180 名大学生 DEA 演示样本，CC BY 4.0，适合当前学生学业效率模块。
- `data/hospital_public.csv`：来自 GitHub `zhjx19/mathmodels-book` 的医院投入、产出和医疗废弃物数据，适合 SBM 与非期望产出分析。
- `data/economy_public.csv`：来自同一仓库的 2005—2009 年中国工业经济面板数据，适合 Malmquist 指数分析。
- `data/demo_dea.csv`：系统自带的正值演示数据，用于快速试运行。
- `data/大学生成绩模板.csv`：教师可按字段结构整理自己的大学生课程成绩数据。

## 数据约束

每一行必须对应一个唯一 DMU；投入和产出字段必须是非负数值；投入和产出不能重复；当前版本至少需要 3 个 DMU。

## 运行方式

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## 模型说明

投入导向模型关注在维持既定产出的前提下，投入最多可以压缩到原来的多少；产出导向模型关注在既定投入下，产出最多可以扩张到什么程度。BCC 模型允许不同 DMU 处于不同规模报酬阶段，CCR 模型假设固定规模报酬。

DEA 结果是样本内相对效率，不代表绝对效率，也不能替代教师对指标定义、学生基础、课程难度和因果关系的判断。对于大学生数据，系统评价的是学习资源投入与学习结果、课程成绩之间的相对转化效率，不是统计意义上的“某个因素导致成绩变化”。跨期 Malmquist 在某些时期前沿不具备共同可行生产集合时会跳过该 DMU-时期对，并在结果中保留可计算的跨期样本。
